주식 스윙 분석기 — 수정판 설치 안내

포함 파일
- streamlit_app.py: 알려줘 버튼으로 실행하는 웹 앱
- requirements.txt: 필요한 Python 라이브러리
- stock_money_flow_scanner.py: 기존 콘솔형 분석기(별도 실행용)

핵심 동작
1. Streamlit 화면에서 분석 시장과 종목 수를 선택합니다.
2. '알려줘' 버튼을 한 번 누르면 종목 데이터를 가져와 분석합니다.
3. 상승 추세, 직전 20거래일 고점 돌파, 거래대금/거래량 증가, 당일 상승률, 데이터 날짜 조건을 모두 충족한 종목만 진입 후보로 표시합니다.
4. 후보가 없으면 매수 신호를 만들지 않습니다.
5. 기본 투자금은 200,000원이며 거래당 계획 손실 예산은 1%(2,000원)입니다. 매수 수량은 위험 기준 수량과 투자금 기준 수량 중 작은 값으로 계산합니다.
6. 마지막 데이터가 오늘 기준 5일보다 오래됐거나 미래 날짜면 해당 종목은 신호 후보에서 제외됩니다.
7. 앱은 주문을 전송하지 않습니다.

GitHub/Streamlit Cloud 배포
1. GitHub 저장소 최상위(root)에 streamlit_app.py와 requirements.txt를 올립니다.
2. stock_money_flow_scanner.py는 앱 실행에 필수 import는 아니지만, 기존 프로젝트 파일을 보존하려면 함께 올려도 됩니다.
3. https://share.streamlit.io/ 에서 GitHub 계정으로 로그인하고 새 앱을 만듭니다.
4. Repository: 본인의 저장소, Branch: main, Main file path: streamlit_app.py 로 지정합니다.
5. Deploy를 누르고 로그에 오류가 없는지 확인합니다.
6. 앱이 뜨면 '알려줘' 버튼을 눌러 실제 분석을 테스트합니다.

오류 해결
- ModuleNotFoundError: requirements.txt가 저장소 최상위에 있는지, 파일명이 정확한지 확인합니다.
- 종목 목록 오류: FinanceDataReader 데이터 제공처 또는 시장 목록 형식이 변경됐을 수 있습니다. 앱의 오류 확인 영역과 Streamlit 로그를 확인합니다.
- 데이터가 없거나 후보가 없음: 휴장일, 데이터 공급처 장애, 데이터 최신성, 진입 조건 때문일 수 있습니다. 후보가 없는 것이 반드시 오류는 아닙니다.
- 실행이 너무 오래 걸림: 분석 종목 수를 50 또는 100으로 낮춥니다. 주식 데이터 제공처 응답 속도에 따라 분석 시간이 달라집니다.

주의
- 종가×거래량은 공식 거래대금이 아닌 추정치입니다.
- 데이터 나이 기준은 달력 날짜 기준이며 5일 초과 시 신호를 제한합니다. 장기 휴장 때는 후보가 없을 수 있습니다.
- ATR 기반 손절 가격은 실제 체결 가격을 보장하지 않습니다. 갭 하락, 수수료, 세금, 슬리피지로 실제 손실이 계산보다 커질 수 있습니다.
- 이 도구는 투자자문이나 수익 보장 도구가 아닙니다.
